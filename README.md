# Ангел SPA - Premium Beauty Salon Website

Welcome to the **Ангел SPA** project, a premium beauty salon website based in Stavropol, Russia. This site showcases a range of services including cosmetology, spa treatments, Thai massage, wellness therapy, and figure correction. It is designed to provide an elegant and user-friendly experience with a focus on premium care.

## Overview

- **Description**: Angel Concept is a premium beauty salon in Stavropol offering cosmetology, spa, Thai massage, wellness therapy, and figure correction services.
- **Author**: Yulia Podgurskaia
- **Language**: Russian 
- **Purpose**: A pet project or portfolio piece to demonstrate a modern salon website with video background, interactive sliders, and service highlights.

## Features

- **Video Background**: A full-screen video (`Angel_bg2.mp4`) enhances the visual appeal with a fixed background.
- **Responsive Design**: Optimized for various screen sizes with a media query for mobile views.
- **Service Slider**: A horizontal accordion slider showcasing six service categories with expandable cards.
- **Navigation Menu**: A bottom header navigation with links to services, about, and contact pages.
- **Appointment Booking**: A prominent call-to-action button for booking appointments.
- **Yandex Rating**: Integration of a Yandex rating widget with a 4.9 rating and 135 reviews.
- **Social Links**: Links to Instagram for social media engagement.
- **Smooth Scrolling**: Enabled for a seamless user experience.

- **CSS3**
